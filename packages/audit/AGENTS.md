# @agent-evals/audit

Checks if a set of run records supports a fair comparison, and reports each check as passed, failed, or not checked.

## Owns

- `src/index.ts`: `auditRecords`, and the list of checks that only the runner can make.
- `src/balance.ts`: both arms ran the same tasks the same number of times.
- `src/failures.ts`: the failure counts of both arms, with a limit of 10 points for the gap.
- `src/versions.ts`: no version changed inside one arm.

## Rules

- A check that the records cannot answer is `not-checked`. Never report it as passed.
- Each check gives the counts that it used in its detail, so the reader can verify it.
