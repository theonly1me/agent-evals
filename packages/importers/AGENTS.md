# @agent-evals/importers

Reads the result files of other harnesses and gives run records. It never starts another harness.

## Owns

- `src/index.ts`: `importRunRecords`, which finds the format of a location, and `armNameOf`.
- `src/harbor.ts`: a Harbor job folder, one `result.json` for each trial.
- `src/inspect.ts`: an Inspect AI log dump, the JSON from `inspect log dump`.
- `src/promptfoo.ts`: a promptfoo JSON output.
- `src/jsonl.ts`: a JSONL file with one run record on each line.
- `src/fixtures/`: real output from Inspect AI 0.3.288 and promptfoo 0.125.1, and a Harbor job in the shape of the Harbor source models.

## Rules

- An importer returns a result. It returns `rejected` with the file and the field for a shape that it does not know. It does not throw, and it does not guess a value.
- A trial with no valid reward becomes an `infra-failure` with no score. Never import it as a score of 0.
- Each format needs a fixture that the real tool wrote. Record the tool version in this guide when you replace a fixture.
- The Harbor fixture follows `src/harbor/models/trial/result.py` of Harbor. A real Harbor job is not in the fixtures yet.

## Tests

Run `bun test` in this folder. The tests use synthetic data and public fixtures, and they call no model.
