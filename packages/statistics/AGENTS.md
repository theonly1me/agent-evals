## Owns

- `src/mersenneTwister.ts`: `createPythonRandom`, a generator that gives the same outputs as Python `random.Random` for the same seed.
- `src/sums.ts`: `exactSum`, `exactMean`, and `compensatedSum`, which match Python `fsum`, `fmean`, and `sum`.
- `src/intervals.ts`: `meanInterval`, `differenceInterval`, and `signFlipPValue`.
- `src/paired.ts` and `src/unpaired.ts`: the interval and the test for paired differences, and the permutation test for two groups.
- `src/holm.ts`, `src/normal.ts`, `src/power.ts`: the Holm correction, the normal quantile, and `powerAnswer`.

## Rules

- Each method takes its seed and round count as input. No method reads the clock or `Math.random`.
- `src/parity.test.ts` compares the methods with a saved Python analysis. A change that breaks an exact match is a defect.
- A function takes numbers and returns numbers. Put run and task logic in `@agent-evals/verdict`.
