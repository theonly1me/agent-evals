## Owns

- `src/build.ts`: `buildReport`, which joins the comparison, the power plan, the other metrics, the arm summaries, and the audit.
- `src/sentences.ts`: the verdict sentence, the evidence sentence, and the notes.
- `src/view.ts`: the one view that every renderer reads.
- `src/text.ts`, `src/markdown.ts`, `src/html.ts`: the renderers.

## Rules

- Every renderer reads the same view, so each format says the same thing.
- The first line of every format is the verdict sentence.
- A report has a power plan only when the verdict is not conclusive.
- Only the main metric gets a verdict. The other metrics are descriptive and carry a Holm-adjusted p-value.
- Escape every name from the results in the HTML report.
